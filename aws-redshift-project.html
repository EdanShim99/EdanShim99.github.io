AWS ELT Pipeline – S3 & Redshift Serverless

Designed and implemented a cloud-native ELT pipeline on AWS using S3 and Redshift Serverless. The architecture follows a medallion design (Bronze → Silver → Gold) and demonstrates incremental ingestion, idempotent MERGE-based upserts, and analytical warehouse modeling for scalable reporting workflows.



Architecture Overview



Key Engineering Concepts

  • Append-only ingestion into S3 Bronze layer partitioned by ingestion date
  • Structured loading into Redshift using COPY and SUPER data type
  • Deduplication using ROW_NUMBER() window functions
  • Incremental, idempotent upserts using MERGE
  • Gold-layer aggregated tables for analytical reporting
