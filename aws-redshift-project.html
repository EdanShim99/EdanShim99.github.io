AWS ELT Pipeline – Redshift Serverless & Airflow (MWAA)

Designed and implemented a cloud-native ELT pipeline on AWS using Amazon S3, Redshift Serverless, and Apache Airflow (MWAA). The architecture follows a Medallion design (Bronze → Silver → Gold) and implements append-only ingestion, idempotent MERGE-based transformations with latest-record-wins logic, and analytical warehouse modeling for scalable reporting workflows.



Architecture Overview



Key Engineering Concepts

  • Append-only ingestion into S3 Bronze layer partitioned by ingestion date
  • Orchestration of ingestion and transformation tasks using Apache Airflow (MWAA)
  • Structured loading into Redshift using COPY and SUPER data type for semi-structured JSON
  • Deduplication using ROW_NUMBER() window functions
  • Idempotent upserts using MERGE
  • Gold-layer aggregated tables for analytical reporting


Orchestration - Apache Airflow (MWAA)

The workflow is orchestrated using Apache Airflow (MWAA), coordinating ingestion, Bronze loading, Silver transformations, and Gold aggregations with explicit task dependencies and execution monitoring. The DAG enforces execution order and ensures reliable, repeatable pipeline runs.
